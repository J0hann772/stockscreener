# Паттерны проектирования в проекте MarketView

## 1. Factory Method (Фабричный метод)

**Где используется:** `fastapi_service/indicators/Indicators.py`, класс `IndicatorFactory`

**Что делает:**  
У нас есть 10 разных индикаторов (RSI, EMA, SMA, MACD и т.д.).
Вместо того чтобы везде писать `if indicator == 'rsi': return RSIIndicator(...)`,
мы сделали фабрику — передаёшь строку с именем, получаешь нужный объект.

```python
indicator = IndicatorFactory.create('rsi', {'length': 14})
```

**Зачем это нужно:**  
Легко добавить новый индикатор — просто регистрируем его в словаре `REGISTRY`.
Остальной код не меняется.

---

## 2. Template Method (Шаблонный метод)

**Где используется:** `fastapi_service/indicators/Indicators.py`, класс `BaseIndicator`

**Что делает:**  
Все индикаторы устроены одинаково: у каждого есть метод `calculate()` (считает индикатор)
и `last()` (возвращает последнее значение). Мы вынесли этот общий «скелет» в абстрактный
базовый класс `BaseIndicator`, а конкретные классы (RSIIndicator, EMAIndicator и т.д.)
реализуют своё поведение внутри этих методов.

```python
class BaseIndicator(ABC):
    @abstractmethod
    def calculate(self, df): ...
    @abstractmethod
    def last(self, df): ...
```

**Зачем это нужно:**  
Не надо каждый раз придумывать интерфейс заново. Все индикаторы работают предсказуемо
и одинаково — движок анализа вызывает `calculate()` и `last()` не зная, какой именно индикатор.

---

## 3. Strategy (Стратегия)

**Где используется:** `fastapi_service/schemas/analyze_engine.py`, логика анализа стратегий

**Что делает:**  
Пользователь создаёт торговую стратегию — набор условий с AND/OR логикой.
Каждое условие — это отдельный «алгоритм» проверки: RSI < 30, EMA > SMA, MACD > 0 и т.д.
При запуске анализа движок берёт список тикеров и прогоняет каждый через условия стратегии.
Условия взаимозаменяемы — можно собрать любую комбинацию без изменения кода движка.

**Зачем это нужно:**  
Пользователь сам определяет логику отбора акций. Движок анализа не знает
заранее, какие условия будут — он просто последовательно их выполняет.
Это и есть паттерн Стратегия: алгоритм подбирается на лету.
