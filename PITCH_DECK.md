# Питч-дек: StockScreener (FinTech SaaS)

**Целевая аудитория:** Розничные инвесторы, трейдеры, аналитики.
**Формат:** Оптимизировано для импорта в Gamma.app (Маркдаун).

---

## Слайд 1: Заголовок и Проблема
**Заголовок:** StockScreener: Демократизация алгоритмического анализа
**Текст:**
* **Сложность:** Существующие инструменты алгоритмического трейдинга (например, TradingView) требуют знания сложных языков программирования (Pine Script) для создания кастомных стратегий.
* **Дороговизна:** Профессиональные скринеры стоят неоправданно дорого для обычного розничного инвестора.
* **Ограниченность:** Бесплатные или банковские решения слишком примитивны и подходят только для базового фундаментального анализа, игнорируя глубокий технический анализ.

---

## Слайд 2: Решение (StockScreener)
**Заголовок:** Интуитивный No-Code скринер акций
**Текст:**
* **No-Code Конструктор:** Создавайте сложные торговые стратегии с помощью визуального интерфейса без написания единой строчки кода.
* **Гибкая логика:** Поддержка сложных условий (И/ИЛИ группы), пересечений индикаторов (SMA, EMA, RSI, MACD) и паттернов.
* **Высокая скорость:** Микросервисная архитектура обеспечивает быстрый расчет стратегий на лету, анализируя тысячи тикеров одновременно.

---

## Слайд 3: Архитектура и Технологический Стек
**Заголовок:** Надежная и масштабируемая платформа
**Текст:**
* **Backend:** Разделение на два микросервиса:
  * **Django (Монолит):** Управление пользователями, аутентификация (JWT), биллинг и сохранение пользовательских стратегий в PostgreSQL.
  * **FastAPI (Счетчик):** Высокопроизводительный сервис для математических расчетов индикаторов с использованием Pandas/NumPy.
* **Инфраструктура:**
  * Асинхронные задачи через Celery + Redis для обработки очередей расчетов.
  * Интеграция с Financial Modeling Prep (FMP) API для получения исторических данных о котировках.
* **Развертывание:** Полная контейнеризация через Docker Compose.

## Слайд 5: Анализ конкурентов
**Заголовок:** Почему мы выигрываем (Сравнение)
**Текст:**
* **TradingView:** Дорогие Pro-подписки (от $15 до $60+ в месяц), требует знания языка Pine Script для создания своих стратегий. StockScreener предлагает интуитивный No-Code конструктор.
* **Finviz:** Устаревший интерфейс, ограниченный набор индикаторов, нет кастомной логики И/ИЛИ. StockScreener дает современный UI и гибкую логику.
* **Скринеры брокеров (Тинькофф/Альфа):** Слишком примитивны, подходят только для фундаментального анализа. StockScreener дает глубокий технический анализ.

## Слайд 6: Бизнес-модель и Монетизация
**Заголовок:** Монетизация (Freemium SaaS) и Юнит-экономика
**Текст:**
* **Тарифы:**
  * **Basic (Бесплатно):** Доступ к графикам, до 10 тикеров в портфеле, 1 простая стратегия (макс. 2 индикатора), ограниченная история.
  * **Pro ($9.99/мес):** Безлимитные стратегии, сложная логика (OR-группы), скрининг до 100 тикеров одновременно, приоритет в очереди расчетов.
  * **Будущее (B2B):** Доступ по API и White-label решения для небольших инвестиционных фондов и Telegram-каналов.
* **Экономика и Окупаемость:**
  * Основной фиксированный расход — Premium подписка на FMP API ($49 в месяц).
  * Подписка предоставляет лимит в **750 API запросов в минуту**. Благодаря кэшированию в Redis, этого лимита хватит для обслуживания тысяч активных пользователей.
  * **Точка безубыточности:** Достигается всего при **5 пользователях** тарифа Pro (5 * $9.99 = $49.95).
  * Дальнейший рост пользователей приносит чистую прибыль. Например, при 100 платных пользователях наш доход составит ~$1000, чистая прибыль ~$950/мес. При 1000 пользователях — около $9,941/мес.
