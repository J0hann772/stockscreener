Обзор проекта
=============

MarketView — веб-приложение для скрининга акций по техническим индикаторам.

Архитектура
-----------

Проект состоит из двух микросервисов:

* **Django** (порт 8000) — управление пользователями, стратегиями, тикерами
* **FastAPI** (порт 8001) — расчёт индикаторов, анализ, OHLCV данные

Дополнительные компоненты:

* **PostgreSQL** — база данных
* **Redis** — брокер задач Celery + кэш данных
* **Celery Worker** — фоновая обработка анализа

Паттерны проектирования
-----------------------

В проекте реализованы следующие паттерны:

1. **Factory Method** — ``IndicatorFactory.create()``
2. **Template Method** — абстрактный ``BaseIndicator``
3. **Strategy** — торговые стратегии с AND/OR условиями

Запуск
------

.. code-block:: bash

   docker compose up --build
